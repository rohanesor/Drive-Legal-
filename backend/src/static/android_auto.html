Setup Instructions

  1. Download and install the latest compatible Android APK on your phone.
  2. Connect your Android device to your car's console using an approved USB data cable (or via wireless connection if supported).
  3. Open the car dashboard display and select the DriveLegal app icon.
  4. Follow the on-screen configuration wizard to enable real-time notifications.

Known Limitations

  • Voice Recognition: Voice prompts rely on local Whisper-tiny model files, which require adequate on-device storage.
  • GPS Availability: Best precision is achieved when GPS location tracking permissions are set to "Allow all the time".
